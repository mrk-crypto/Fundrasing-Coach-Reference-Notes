# Fundraising Coach Reference Tool
# 募款教练参考工具

A bilingual (English/Chinese) interactive coaching reference based on **Situational Leadership II**.

基于**情境领导 II**模型的中英双语互动教练参考工具。

## 🔗 Live Site · 在线访问

**https://mrk-crypto.github.io/Fundrasing-Coach-Reference-Notes/**

## Features · 功能

- **Overview 总览** — D1–D4 development levels with expandable detail cards
- **Behaviors 行为** — Directive vs Supportive behaviors, Diagnose-Adapt-Communicate framework
- **GROW Model** — Interactive G/R/O/W steps with bilingual sample questions
- **Matching 配对** — Development level ↔ Coaching style pairing table
- **Application 应用** — Support-raising scenarios + observation checklist

## Usage · 使用方式

Open `index.html` in any browser — no internet connection required.

直接用浏览器打开 `index.html` 即可，无需网络连接。
